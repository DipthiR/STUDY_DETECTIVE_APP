# 🕵️ Study Detective – Escape Room Academy

**Study Detective** is an interactive, gamified learning application that transforms traditional studying into an exciting escape-room adventure. Students solve subject-related questions, investigate clues, earn experience points (XP) and unlock new mystery rooms by demonstrating their knowledge.

## 🎯 Project Objective

The main objective of Study Detective is to make learning more engaging, interactive and enjoyable through gamification. It encourages students to improve their problem-solving skills, subject knowledge and logical thinking.

## ✨ Features

- **Multiple Subjects:** Biology, Chemistry, Physics, Mathematics, Data Science, Computer Science, Artificial Intelligence and English.
- **Mystery Cases:** Each subject provides a unique escape-room challenge.
- **Interactive Clues:** Investigate objects in the room to discover questions.
- **Question-Based Challenges:** Answer multiple-choice questions to progress.
- **XP Rewards:** Earn experience points for correct answers and successful escapes.
- **Hint System:** Use XP to receive hints when you need help.
- **Timer and Lives:** Complete challenges within the time limit while managing lives.
- **Progress Tracking:** View completed rooms, total XP and answer accuracy.
- **Case Archive:** Track your learning progress and unlock subsequent rooms.
- **Responsive Design:** Designed to work on desktop and mobile screens.
- **Local Progress Storage:** Saves progress in the browser using localStorage.

## 🚀 Getting Started

### Prerequisites

- A modern web browser such as Chrome, Edge or Firefox.
- A code editor such as Visual Studio Code.
- The Live Server extension in VS Code (recommended).

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/study-detective.git
   ```

2. Open the project folder:

   ```bash
   cd study-detective
   ```

3. Open the folder in Visual Studio Code.

4. Right-click `index.html` and select **Open with Live Server**.

5. Select a subject and start investigating clues.

Alternatively, open `index.html` directly in your web browser.

## 🎮 How to Play

1. Select an available subject.
2. Enter the mystery room.
3. Investigate the unlocked objects.
4. Read the question associated with each clue.
5. Select the correct answer to earn XP and unlock the next clue.
6. Use hints when necessary.
7. Complete the final challenge before time or lives run out.
8. Check the Case Archive to view your progress.

- Progress is stored locally in the browser.
- Data is not synchronized between devices.
- The current question bank is predefined.
- The application does not require a backend server.
